# docs/adr/

Permanent home for Architecture Decision Records. New ADRs land here with sequential numbers.

Existing records are **superseded historical decisions** (see banners in each file); the specific reversals
are itemized in [`../TRACE-CANONICAL-TRUTH.md`](../TRACE-CANONICAL-TRUTH.md) §12 "Settled / Superseded Paths".
They are preserved unmodified (banner prepended) for lineage — never silently rewritten into modern truth.
